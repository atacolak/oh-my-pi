List peer omp sessions: saved journals and live socket owners, named and unnamed.

Each entry gives the canonical session UUID (stable across renames), the actor handle when named (a mutable label — never a role, title, or permission), and truthful availability proven by an actual handshake with the published owner: `live` (reachable and answering as that exact session), `offline` (saved journal, no live owner), or `unavailable` (published but not verifiably reachable — never trust a stale sidecar or a reused PID). Also address facts: working directory, journal file, provider/model of the live owner. `query` filters by handle or UUID substring; `live_only` keeps proven-live sessions; `limit` bounds the output (default 25, max 100) with an explicit truncation note. Send mail to a live peer with the `agent_mail` tool; an offline or unavailable session cannot receive.
