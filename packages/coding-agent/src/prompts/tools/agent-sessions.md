List peer omp sessions: saved journals and live socket owners, named and unnamed.

Each entry gives the stable session UUID, optional mutable handle, working directory, journal and available model information. `live` means the exact owner answered; `offline` means a saved session with no live owner; `unavailable` means the publication could not be verified. `agent_mail` can leave quiet mail for a saved session without waking it. A name or discovery result grants no permissions.
